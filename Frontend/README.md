# Smart HRMS Frontend

Professional role-based React/Vite frontend for the MY-HRMS backend.

## Run

```powershell
cd Frontend
npm install
npm run dev
```

The frontend expects the backend at `http://localhost:5000/api` by default. Create `.env` from `.env.example` if the backend runs elsewhere.

## Developer section

Edit the `developer` object at the top of `src/App.jsx` and replace `public/developer-placeholder.svg` with the final developer photo when ready.
